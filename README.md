# Lab2 — консольный поиск по Википедии

Консольная Java-программа: пользователь вводит поисковый запрос, программа
обращается к API Википедии, печатает найденные статьи и открывает
выбранную статью в браузере.

## Требования

- JDK 21 или новее (`java -version`)
- Интернет для выполнения запросов к `ru.wikipedia.org`
- Maven устанавливать не нужно — в проекте есть Maven Wrapper (`./mvnw`).

## Сборка

```bash
./mvnw clean package
```

Результат — исполняемый fat-jar со всеми зависимостями:

```
target/Lab2-1.0-SNAPSHOT.jar
```

Альтернатива (то же самое через скрипт):

```bash
./build.sh          # только собрать
./build.sh run      # собрать и запустить
```

## Запуск

```bash
java -jar target/Lab2-1.0-SNAPSHOT.jar
```

Пример работы:

```
Введите запрос: test
Было найдено 10 совпадений.
1) "Test"
2) ".test"
...
Выберите нужный вам вариант: 1
```

- `exit` — выход из программы.
- После списка вводится номер статьи (нумерация с 1) — она откроется в браузере.

## Структура проекта

```
Lab2OOP/
├── pom.xml              # конфигурация Maven: Java 21, Gson, сборка fat-jar
├── mvnw, mvnw.cmd       # Maven Wrapper (Linux/macOS и Windows)
├── .mvn/wrapper/        # настройки wrapper (версия Maven 3.9.11)
├── build.sh             # короткий скрипт-обёртка над ./mvnw
├── src/
│   ├── Main.java        # консольный интерфейс: ввод, меню, выбор, браузер
│   ├── Requester.java   # HTTP-запрос к API Википедии
│   └── Parser.java      # разбор JSON-ответа через Gson
├── BUGS.md              # отчёт о тестировании и найденных проблемах
└── target/              # результат сборки (в git не попадает)
```

Внимание: исходники лежат в `src/` (а не в стандартном `src/main/java`),
это учтено в `pom.xml` через `<sourceDirectory>src</sourceDirectory>`.

## Как устроено

1. `Main` читает запрос из консоли и передаёт его в `Requester`.
2. `Requester` кодирует запрос в URL (`URLEncoder`) и выполняет GET к
   `https://ru.wikipedia.org/w/api.php?action=query&list=search&...`.
   Таймауты подключения и чтения — по 10 секунд.
3. `Parser` получает тело ответа, разбирает JSON через Gson и достаёт из
   `query.search` массив результатов (поля `title` и `pageid`).
4. `Main` печатает заголовки и по выбранному номеру формирует ссылку
   `https://ru.wikipedia.org/w/index.php?curid=<pageid>`, которую открывает
   через `Desktop.browse(...)`.

## Зависимости

- [Gson 2.13.1](https://github.com/google/gson) — разбор JSON.
- `maven-shade-plugin` — собирает один jar вместе с Gson.

## Известные проблемы

Подробный отчёт о тестировании (приоритеты, воспроизведение, ожидаемое
поведение) — в файле [BUGS.md](BUGS.md). Коротко о главном:

- при выборе `0` или нажатии Ctrl+D программа падает;
- заголовки печатаются в кавычках, потому что используется `toString()`;
- «Было найдено N» показывает число результатов на странице (10), а не общее
  число совпадений из `totalhits`;
- «Показать больше вариантов» фактически недостижимо: API отдаёт 10 записей.

## Сборка без Maven (резервный вариант)

```bash
javac -encoding UTF-8 -cp ~/.m2/repository/com/google/code/gson/gson/2.13.1/gson-2.13.1.jar \
      -d out $(find src -name '*.java')
java -cp "out:$HOME/.m2/repository/com/google/code/gson/gson/2.13.1/gson-2.13.1.jar" Main
```

Этот способ требует, чтобы Gson уже был скачан в локальный Maven-репозиторий.
